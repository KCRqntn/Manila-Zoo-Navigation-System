# Changes, 23–26 October 2026

## Logging out
- Anyone who logs out (admin, staff or visitor) goes to the home page and sees the welcome window again
  (Open the website / Website QR code / Administrator login).

## Animal photos
- Photos taller than their frame are shown whole over a blurred copy of themselves.
- Always shown whole: Japanese Macaque, Ostrich, Philippine Eagle, Tarictic Hornbill, Samar Cobra,
  Green Imperial Pigeon. Other tall photos are zoomed in slightly. List: `SHOW_WHOLE` in
  `artifacts/manila-zoo/src/components/AnimalImage.tsx`.

## QR codes
- Exhibit and location codes hold a short web link (`<public address>/q/MNL-ZOO-…`), so the normal
  camera app on iPhone and Android opens them. Older prints (`/qr-scan?code=…`) still work.
- Every QR code: black on white, 4-square white border, error correction "M" (`QR_STYLE` in
  `artifacts/manila-zoo/src/lib/qrLinks.ts`).
- Admin → Exhibit QR Codes: previews and downloads contain the link; **Print all** prints every
  active code (3 per row, A4). Reprint whenever the public address changes.
- The website's own scanner reads QR codes only and uses the phone's built-in reader when available.

## Map
- "Select location" scrolls the map into view on phones.
- Tapping a place pin while selecting a location no longer crashes the page (pin coordinates are
  stored as numbers).

## AI Guide (chatbot)
- Answers only the detail asked (habitat, diet, feeding time, one fun fact, status, weight, height,
  lifespan, scientific name, classification, exhibit). Logic: `artifacts/api-server/src/lib/animalAnswers.ts`.
  BERT still decides the topic; this layer picks the field. No retraining.
- Empty database fields → "Sorry, I couldn't find that information in the Manila Zoo database."
- Follow-ups ("Habitat?", "What does it eat?") use the last animal in the chat (30 minutes, resets
  when the server restarts).
- Name matching several animals ("macaque") → asks which one; the reply ("the Japanese one") answers it.
- Unknown animals ("unicorn") → says it isn't in the database.
- Rankings and world trivia ("largest animal in the world") and off-topic questions → refused.
- The animal list only for an explicit request, filtered by status or group ("Which animals are
  endangered?", "What birds can I see?").
- Tests: 76/76 regression questions pass, plus the database-only test cases.
